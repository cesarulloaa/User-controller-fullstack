# 🌐 Full-Stack Web Application Template (Spring Boot + React)

This repository contains a full-stack web application template that integrates Spring Boot for the backend and React for the frontend.
It is designed as a starting point for building modern, scalable, and maintainable web applications.

Backend: Spring Boot

Frontend: React
